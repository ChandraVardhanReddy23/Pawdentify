# Screenshots

Place the following screenshots in this directory. The main README will
render them automatically.

| Filename | Screen to capture |
|----------|-------------------|
| `landing_light.png` | Home page hero section in light mode |
| `landing_dark.png` | Home page hero section in dark mode |
| `upload.png` | Upload area with a photo selected, before predict |
| `result.png` | Prediction result with breed info tabs visible |
| `breed_search.png` | `/search-breed` page with search results |
| `breed_detail.png` | Breed detail modal or expanded card |
| `dashboard.png` | `/dashboard` page showing history + pet profiles |
| `services.png` | `/services` page with Mappls map and search |

Recommended capture size: 1280×800 or native browser width.
Use any screenshot tool (Snipping Tool, browser DevTools, etc.).
